# Lua Travel — new website draft

This is a static GitHub Pages website for Lua Travel. It is a separate preview and does not replace the existing isoCMS website.

## Preview

Open `index.html` in a browser or serve this folder with any static web server. To publish through GitHub Pages, select the repository's `main` branch and `/ (root)` in **Settings → Pages**.

## Before replacing the current website

- Move the image files into this repository. This draft temporarily references images hosted by the existing website.
- Replace the email links with a proper enquiry form if submissions must be stored in a CRM.
- Rebuild booking, inventory, multilingual pages, and payment features separately. They are not part of this static draft.
- Review all copy, imagery, and brand details before directing the main domain here.

No passwords, payment configuration, customer records, or isoCMS source code are included.
